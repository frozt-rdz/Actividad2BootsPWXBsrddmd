Presentación de la Actividad

El objetivo de esta actividad es unir, a manera de rompecabezas, las prácticas realizadas a lo largo del Tema 2: HTML, XML y CSS. Buscamos crear un página web con un estilo minimalista a la vez que atractivo y responsivo, con una estética oscura que evoque al Día de los Muertos.

Para lograrlo, integramos, de manera equilibrada, el grid, tanto de Bootstrap como el de CSS, así como algunas reglas de este último, demostrando el control sobre cómo se despliegan los elementos en diferentes tamaños de pantalla. A continuación, detallamos las tecnologías empleadas.

CSS Grid Layout

Presenta un sistema de cuadrícula bidimensional para CSS. Las cuadrículas se pueden utilizar para posicionar áreas principales de la página o pequeños elementos de la interfaz de usuario.

Nos permitió definir tamaños mínimos minmax y usar auto-fit para adaptar las columnas fluidamente al tamaño del monitor sin usar @media excesivos.

Bootstrap 5

Aprovechamos las 12 columnas que vimos en clase para dividir de manera general la página, así como sus componentes preconstruidos para el Navbar interactivo y el Carrusel de imágenes.

Pese a que en clase usamos Bootstrap 6, preferimos usar la versión 5 la cual ya es estable respecto a la Alpha.

HTML5 y CSS3

Utilizamos HTML5 para estructurar y organizar el contenido de las páginas empleando etiquetas como main, section y header. Gracias a CSS3 logramos la animación tipo hover (desplazamiento en el eje Y) y el degrado (mask-image) para mejorar la presentación de las fotografías.
